# Desarrollo Web en Entorno Cliente — 2.º DAW

Ejercicios de **JavaScript** del módulo de Desarrollo Web en Entorno Cliente de 2.º de DAW (curso 2026-2027), organizados por unidad. Cada tarea es una página HTML con su script.

## Tecnologías

HTML5 · CSS3 · JavaScript (ES6+: `let`/`const`, funciones flecha, `Set`, `Map`, JSON, DOM)

## Índice

| Unidad | Tareas |
|---|---|
| [`ud02-sintaxis-javascript`](ud02-sintaxis-javascript) | Cálculo de edad · Aprobado o suspenso · Horario · Adivina la letra |
| [`ud03-arrays-sets-maps`](ud03-arrays-sets-maps) | Colores · Números aleatorios · Creación de conjuntos (`Set`) · Mapa de identidad (`Map`) · Ordenación de un array de números |
| [`ud04-funciones-y-cadenas`](ud04-funciones-y-cadenas) | Adivina la palabra · Filtrar palabras con tilde · Funciones flecha · Gestión y análisis de palabras |
| [`ud05-dom-y-json`](ud05-dom-y-json) | Práctica Festivales (datos JSON) · Práctica Productos · Validación de etiquetas |

## Cómo verlo

Abre el `index.html` (o el `.html` de la tarea) en el navegador. No hace falta instalar nada.
